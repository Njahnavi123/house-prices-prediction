# House Price Prediction

This project predicts house prices using a Random Forest model.

## Files

- main.py – Python script with the project code.
- house_prices.csv.zip – compressed dataset (too large for GitHub).

## How to Run

1. Unzip `house_prices.csv.zip` in the same folder.
2. Install dependencies:

   pip install pandas scikit-learn matplotlib

3. Run the script:

   python main.py
